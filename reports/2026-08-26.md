### 🥈 Upgrade K's long-horizon research agent with Recuris/AutoSaddler-style memory + harness auto-tuning
**Rationale:** Two credible papers today ([Recuris](http://arxiv.org/abs/2608.24876v1), [AutoSaddler](https://huggingface.co/papers/2608.23041)) address the exact failure mode killing K's multi-step target-discovery agent — trajectory drift on long tasks. Integrating experiential-working-memory patterns closes a real reliability gap and is a direct answer to Biomni's agentic pitch.
**Effort:** Medium-High (6–8 weeks) — memory architecture refactor plus offline eval harness on internal long-horizon benchmarks.

### 🥉 Enterprise admin & audit surface parity with ChatGPT Work
**Rationale:** OpenAI's Admin plugin sets a new bar for what pharma IT/security expects: usage analytics, permission management, per-user limits, and admin request queues. Without parity, K risks stalling in AZ/Sanofi procurement even when scientific value is superior — and it's a prerequisite for EU AI Act audit trails.
**Effort:** Medium (4–6 weeks) — largely surface-area work over existing IAM + telemetry primitives.
