## 6. Build Signals for K Platform

### 🥇 Deterministic Tool-Call Layer for All Clinical/Numerical Outputs
**Rationale:** The [clinical math solver paper](https://huggingface.co/papers/2609.10728) plus Perplexity's Astra-level autonomy trend mean K cannot ship any biomarker cutoff, dosing recommendation, or trial-eligibility number generated by raw LLM tokens. A deterministic function-call layer (with signed audit records) is both a GxP prerequisite and a competitive differentiator vs. Benchling Assistant.
**Effort:** Medium (6–8 weeks) — schema design, function registry, integration with existing agent orchestrator, audit-log persistence.

### 🥈 Federated Multimodal Linkage Reference Architecture — Productize the Pediatric Oncology Pattern
**Rationale:** The [Nature Methods-adjacent PubMed publication on privacy-preserving multimodal linkage](https://pubmed.ncbi.nlm.nih.gov/42728728/) is a citable, peer-reviewed pattern that mirrors K's federated thesis. Packaging it as a reference architecture with SPLENDID-style continuous-ancestry handling gives sales a concrete deliverable for AZ/Sanofi multi-site deals.
**Effort:** Large (Q4 initiative) — reference implementation, DPIA templates, deployment playbook.

### 🥉 Attention Sparsification + Disaggregated Serving for Phikon/Multimodal Inference
**Rationale:** [SAS](http://arxiv.org/abs/2609.13141v1) and [subquadratic disaggregation](http://arxiv.org/abs/2609.13134v1) together offer a plausible 2–4× cost reduction for WSI + long-context multimodal inference. As enterprise inference volumes grow with AZ/Sanofi rollouts, unit economics will dominate margin — worth a spike now.
**Effort:** Medium (spike: 3 weeks; production: 8–10 weeks if spike validates).
