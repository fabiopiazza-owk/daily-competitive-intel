## 6. Build Signals for K Platform

### 🥇 Multiomics reference-calibrator validation layer
**Rationale:** Nature Biotech is codifying reference materials as the reproducibility standard for AI-ready multiomics. Pharma QA will start demanding it in RFPs (AZ/Sanofi validation packages). Being first to bake calibrator-based drift detection into K's ingestion pipeline is a defensible trust moat and blunts "how do we know your model outputs are reproducible" objections.
**Effort:** Medium (4–6 weeks) — ingestion validators, calibrator reference dataset onboarding, model-card additions.

### 🥈 K conversational agent over pharma R&D data lake (MCP-based)
**Rationale:** OpenAI's ChatGPT-to-EHR move sets buyer expectations for a conversational data layer. K needs its own agentic front-door over pathology/genomics/clinical stores, ideally MCP-compliant to avoid platform lock-in. Without this, K risks being reduced to a "model backend" while OpenAI/Google own the user relationship.
**Effort:** Large (1–2 quarters) — MCP servers per data source, agent orchestration, LLM-as-judge eval harness (per AgentJudgeBench).

### 🥉 Adaptive virtual screening module benchmarked against Nature Biotech SOTA
**Rationale:** Virtual screening at billion-compound scale is now published SOTA; K's drug discovery narrative needs a headline capability that competes with or integrates this method. High-signal for AZ/Sanofi hit-finding conversations and directly measurable vs. published baselines.
**Effort:** Medium-Large (8–10 weeks) — implement/integrate adaptive screening, run on K's compound + target data, publish internal benchmark.
